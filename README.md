The repository contains analysis codes of high-resolution Weather Research and Forecasting Model (WRF) experiments over Sydney, Australia for four different urban morphological representations with regards to research presented in:

Fazeli, M., Nazarian, N., Evans, J. P., Lipson, M. J., Gabeiras Penas, J., Sharma, Sh., Martilli, A. (2026) **Are high-resolution urban datasets necessary for accurate heat exposure modelling in cities?** Submitted to Urban Climate.

Please access the WRF files here: [https://doi.org/10.5281/zenodo.18960698](https://doi.org/10.5281/zenodo.18960698)
